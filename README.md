## Навіщо

В агенції щодня треба звітувати, скільки часу пішло на кожен проєкт. До вечора половина дня стирається з пам'яті: що це було о 11:40 — ТЗ, звіт чи листування з клієнтом? Таймери «старт/стоп» теж не рятують: їх забувають вмикати.

Bison Time Checker (BT) знімає цю роботу. Він працює у фоні, сам розкладає день по проєктах і до вечора має готові цифри для звіту: години, хвилини та чернетку коментаря.

**Для кого.** Створено для співробітників Inweb, але підійде будь-кому, хто веде кілька клієнтських проєктів одночасно: SEO-спеціалістам, маркетологам, контент-менеджерам, проджектам.

## Що вміє

- **Сам визначає проєкт.** Проєкт — це домен клієнта. BT знаходить його в заголовку активного вікна: у назві документа, задачі, файлу чи вкладки браузера.
- **Документи за конвенцією.** Назва `shop.com.ua / ТЗ №5 / Виправлення помилок` одразу дає проєкт, документ і задачу.
- **Таск-менеджери.** Задача з доменом клієнта в назві йде в цей проєкт, а планувальник чи списки задач — у проєкт, над яким ти працював поруч у часі.
- **Інструменти SEO.** Краул у Screaming Frog (`https-site-com-ua-`) або URL у заголовку вікна теж визначають клієнта.
- **Нові клієнти без налаштувань.** Новий домен у назві документа чи задачі сам стає проєктом.
- **Звіт за хвилину.** Картка кожного проєкту показує «2 год 35 хв», як у формі звіту, рядки з яких склався час і чернетку коментаря з кнопкою «Копіювати».
- **Чесний час.** Простій без миші й клавіатури, заблокований екран і сон не рахуються. Будь-який рядок можна вимкнути, а час дзвінка додати вручну.
- **Пауза.** Кнопка або `Alt+Shift+P` з будь-якої програми. Поки облік на паузі, іконка помаранчева, тож забути про неї складно.
- **«Інше» як шпаргалка.** Хронологія всього, що не потрапило в проєкти, щоб згадати, що ти шукав і досліджував. Будь-який запис переноситься в проєкт одним кліком.

## Як BT визначає проєкт

| У заголовку вікна | Куди йде час |
| --- | --- |
| `shop.com.ua / ТЗ №5 / Виправлення помилок` (документи Google і все, назване так само) | shop.com.ua, рядок «ТЗ №5 · Виправлення помилок» |
| `Inweb / Навчання / GEO` | внутрішній проєкт Inweb |
| Домен відомого проєкту будь-де: `shop.com.ua - SEO-комплекс`, `shop.com.ua outreach.xlsx` | shop.com.ua |
| Заголовок починається з нового домену: `newclient.ua - SEO-комплекс` | новий проєкт newclient.ua створюється сам |
| URL або краул Screaming Frog: `https://site.com.ua/…`, `https-site-com-ua-` | site.com.ua (новий проєкт — після хвилини роботи) |
| Таск-менеджер без домену в назві: планувальник, списки | проєкт, над яким працював у межах 15 хв до або після |
| Твоє правило: «Looker Studio» → shop.com.ua, figma → shop.com.ua | вказаний проєкт |
| Усе інше: месенджери, пошта, сайти без домену клієнта в заголовку | «Інше»: у звіт не йде, переноситься вручну |

Обмеження, про яке варто знати: BT бачить лише заголовок вікна, а не адресу сторінки. Вкладка без домену клієнта в заголовку (наприклад, Search Console) потрапить в «Інше». Це виправляється правилом за фрагментом заголовка.

## Як користуватися

1. Завантаж `BisonTimeChecker-…-win-x64.zip` з [Releases](https://github.com/iEuegene/Bison-Time-Checker/releases/latest).
2. Розпакуй папку `BisonTimeChecker` у постійне місце й запусти `BisonTimeChecker.exe`. Встановлювати нічого не треба, .NET уже в папці.
3. Програма з'явиться в треї й надалі стартуватиме разом з Windows. Клік по іконці відкриває день.
4. Наприкінці дня перенеси в звіт години й хвилини кожного проєкту, скопіюй коментар і натисни «Внесено».

Порада: називай документи за схемою `домен / документ / задача`. Тоді BT не помиляється взагалі.

Детальна інструкція, список змін і правова інформація є в самій програмі: **Налаштування → Довідка**.

> Програма поки не підписана сертифікатом. Windows SmartScreen може попередити про невідомого видавця: «Докладніше» → «Виконати в будь-якому разі».

**Оновлення:** вийди з BT через меню в треї, заміни папку новою версією, запусти. Твої дані лежать окремо й нікуди не зникнуть.

## Приватність

- **Жодного інтернету.** BT не надсилає даних нікуди: ні на сервер, ні в аналітику.
- Усе зберігається локально в `%LOCALAPPDATA%\BisonTime`: JSON-файл на кожен день і налаштування.
- Заголовки вікон зберігаються 7 днів, підсумки днів — 30 днів.
- BT не читає вміст вікон і не перехоплює клавіатуру. Простій визначається за системним часом останнього вводу.

## Для розробників

```
BisonTime.Core/    логіка без Windows API: розбір заголовків, трекер, звіт, сховище
BisonTime.App/     WPF-програма: трей, активне вікно, простій, гаряча клавіша, інтерфейс, довідка
BisonTime.Tests/   тести ядра без залежностей: dotnet run --project BisonTime.Tests
tools/make-icons.py   іконки
```

Збірка — GitHub Actions на Windows. Кожен push у `main` прогоняє тести, збирає програму й публікує zip у Releases. Локально на Windows:

```
dotnet publish BisonTime.App -c Release -r win-x64 --self-contained -o out/BisonTimeChecker
```
