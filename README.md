# Bison Time Checker (BT)

Розширення для Chrome. Саме рахує, скільки часу ти провів над кожним проєктом, і до кінця дня видає готові дані для щоденного звіту Inweb: проєкт, години, хвилини та чернетку коментаря.

Пара до [Bison Switcher](https://github.com/iEuegene/Bison-Switcher).

## Як BT визначає проєкт

Проєкт — це домен клієнта. Найточніше BT працює з документами Google, названими за конвенцією:

```
домен / документ / задача
shop.com.ua / ТЗ №123 / Виправлення помилок
Inweb / Навчання / GEO
```

- **Google Docs, Sheets, Slides** — проєкт береться з першого сегмента назви. Новий домен сам стає проєктом.
- **Search Console, Ahrefs, Serpstat** — проєкт береться з ресурсу або цілі в адресі, якщо це домен відомого проєкту.
- **Сайт клієнта** та його піддомени (адмінка, тестовий субдомен).
- **Назва домену в заголовку сторінки** — Planfix, CRM, пошук: якщо в заголовку є домен відомого проєкту (`paramedic.ua - SEO-комплекс / ТЗ №57`), сторінка рахується до нього.
- **Inweb** — внутрішній проєкт: навчання, зустрічі, внутрішні задачі.
- Усе інше потрапляє в **«Інше»**. Цей блок показується за хронологією і в звіт не входить. Будь-який запис з нього можна перенести в проєкт одним кліком, а BT запропонує зробити з цього правило.

## Що рахується

- Лише активна вкладка у вікні Chrome, яке зараз у фокусі.
- 3 хв без миші й клавіатури — облік ставиться на паузу. Після повернення з'являється питання «додати до проєкту чи викинути».
- Заблокований екран, сон ноутбука або закритий Chrome не рахуються.
- **Пауза** — велика кнопка в попапі або `Alt+Shift+P`. Поки облік на паузі, іконка помаранчева з ❚❚.
- Під проєктами є рядок «Поза обліком»: скільки часу BT нічого не рахував і чому (інша програма, простій, пауза).
- Підсумок проєкту округлюється до 5 хв. Рядки всередині проєкту показуються точно.

## Приватність

Сервера немає, і розширення не робить жодного мережевого запиту: CSP прямо забороняє `connect-src`. Дані лежать у `chrome.storage.local` на твоєму комп'ютері. Повні адреси зберігаються 7 днів, підсумки дня — 30 днів. BT не читає вміст сторінок, лише їхні адреси та назви.

Дозволи: `tabs`, `idle`, `alarms`, `storage`.

## Встановлення (тестова версія)

1. Завантаж `bison-time-checker-X.Y.Z.zip` з [Releases](https://github.com/iEuegene/Bison-Time-Checker/releases) і розпакуй у постійну папку.
2. Відкрий `chrome://extensions` і ввімкни «Режим розробника».
3. Натисни «Завантажити розпаковане» і вибери розпаковану папку (ту, де лежить `manifest.json`).
4. Закріпи BT на панелі розширень.

Оновлення: розпакуй нову версію в ту саму папку й натисни ↻ на картці розширення в `chrome://extensions`. Дані при цьому зберігаються.

## Розробка

```
npm test                    # юніт-тести (node:test, без залежностей)
npm run build               # dist/bison-time-checker-<version>.zip
python3 tools/make-icons.py # перемалювати іконки (потрібен Pillow)
```

Корінь розширення — `src/`. Збирача немає: це чисті ES-модулі.

| Файл | Що робить |
| --- | --- |
| `src/background.js` | Сервіс-воркер: передає події вкладок, фокусу та простою в трекер |
| `src/lib/tracker.js` | Відрізки часу, пульс, простій, розріз опівночі, очищення старих даних |
| `src/lib/classify.js` | Адреса + назва → проєкт і рядок звіту |
| `src/lib/report.js` | Звіт дня: групи, округлення, «Інше», чернетка коментаря |
| `src/popup/`, `src/options/` | Інтерфейс у фірмовому стилі Inweb |

Сторонній код: [psl](https://github.com/lupomontero/psl) (Public Suffix List, MIT), шрифти Geist та Unbounded (SIL OFL).
