# Bison Time Checker (BT)

Програма для Windows, яка живе в треї й сама рахує, скільки часу ти провів над кожним проєктом. До кінця дня в ній уже готові дані для щоденного звіту Inweb: проєкт, години, хвилини та чернетка коментаря.

Пара до [Bison Switcher](https://github.com/iEuegene/Bison-Switcher) — окрема програма з тим самим фірмовим стилем.

## Як BT визначає проєкт

Раз на секунду BT дивиться на активне вікно: яка програма і який у нього заголовок. Для браузерів (Chrome, Edge, Firefox…) береться назва вкладки. Проєкт — це домен клієнта:

| Що у заголовку | Куди йде |
| --- | --- |
| `shop.com.ua / ТЗ №123 / Виправлення помилок` (Google Docs і все, назване так само) | shop.com.ua, рядок «ТЗ №123 · Виправлення помилок» |
| `Inweb / Навчання / GEO` | Inweb — внутрішні задачі, навчання, зустрічі |
| Домен відомого проєкту будь-де: `paramedic.ua - SEO-комплекс`, `ti.ua outreach.xlsx` | paramedic.ua, ti.ua |
| Заголовок починається з нового домену: `covere2.eu - SEO-комплекс` (задача Planfix) | новий проєкт covere2.eu створюється сам |
| Planfix без домену в назві (планувальник, списки) | проєкт, над яким ти працював у межах 15 хв до або після |
| URL у заголовку: `https://site.com.ua/…` або краул Screaming Frog `https-caffitalia-com-ua-` | caffitalia.com.ua; новий проєкт створюється після хвилини роботи |
| Твоє правило: «Looker Studio» → ti.ua, figma → shop.com.ua | вказаний проєкт |
| Усе інше (Telegram, пошта, сайти без домену клієнта в заголовку) | «Інше»: хронологія, у звіт не йде, переноситься в проєкт одним кліком |

Чого BT не бачить: адреси сторінки. Search Console чи сайт клієнта без його домену в заголовку вкладки потраплять в «Інше». Виправляється правилом за фрагментом заголовка.

## Що рахується

- Тільки вікно, яке зараз активне.
- 3 хв без миші й клавіатури — облік на паузі. Хвилини до цього моменту рахуються, а після повернення BT питає: «додати простій до проєкту чи викинути?».
- Заблокований екран, сон, вимкнений комп'ютер не рахуються.
- **Пауза:** кнопка у вікні BT або `Alt+Shift+P` з будь-якої програми. Поки облік на паузі, іконка в треї помаранчева.
- Кожен рядок проєкту рахується щонайменше як 1 хв. Підсумок проєкту округлюється до 5 хв (налаштовується).
- Рядок «Поза обліком» показує, скільки часу BT нічого не рахував і чому.

## Приватність

Мережі немає взагалі. Дані лежать у `%LOCALAPPDATA%\BisonTime`: JSON-файл на кожен день, налаштування і журнал. Заголовки вікон зберігаються 7 днів, підсумки — 30 днів. Вміст вікон BT не читає. Хуків клавіатури немає: простій береться із системного часу останнього вводу.

## Встановлення

1. Завантаж `BisonTimeChecker-…-win-x64.zip` з [Releases](https://github.com/iEuegene/Bison-Time-Checker/releases).
2. Розпакуй папку `BisonTimeChecker` у постійне місце й запусти `BisonTimeChecker.exe`. .NET ставити не треба: усе потрібне лежить у папці.
3. SmartScreen може попередити про невідомого видавця: «Докладніше» → «Виконати в будь-якому разі».

## Розробка

```
BisonTime.Core/    логіка без Windows API: класифікація заголовків, трекер, звіт, файлове сховище
BisonTime.App/     WPF-програма: трей, читання активного вікна, простій, гаряча клавіша, вікна
BisonTime.Tests/   тести ядра без залежностей:  dotnet run --project BisonTime.Tests
tools/make-icons.py   іконки (паралелограм Inweb, BT / пауза)
```

Збірка exe — GitHub Actions на Windows (`.github/workflows/build.yml`). Кожен push у `main` публікує zip у Releases.

Локально на Windows:

```
dotnet publish BisonTime.App -c Release -r win-x64 --self-contained -o out/BisonTimeChecker
```
