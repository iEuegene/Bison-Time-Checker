Bison Time Checker для Windows — облік часу по проєктах для щоденного звіту. Що змінилось у цій версії, дивись у програмі: Налаштування → Довідка → «Що нового».

**Встановлення:** завантаж `BisonTimeChecker-…-win-x64.zip`, розпакуй папку `BisonTimeChecker` у постійне місце й запусти `BisonTimeChecker.exe`. Програма з'явиться в треї й надалі стартуватиме з Windows. Встановлювати .NET не треба.

Програма поки не підписана сертифікатом, тому SmartScreen може попередити про невідомого видавця: «Докладніше» → «Виконати в будь-якому разі».

**Оновлення:** вийди з BT (правий клік на іконці → Вийти), заміни вміст папки, запусти. Дані лежать окремо, в `%LOCALAPPDATA%\BisonTime`.
