Bison Time Checker для Windows: облік часу по проєктах для щоденного звіту Inweb.

**Встановлення:** завантаж `BisonTimeChecker-…-win-x64.zip`, розпакуй `BisonTimeChecker.exe` у постійну папку (наприклад, `C:\Users\<ти>\Apps\BisonTime`) і запусти. Програма з'явиться в треї й надалі стартуватиме з Windows.

Перший запуск: Windows SmartScreen може попередити про невідомого видавця (exe не підписаний) → «Докладніше» → «Виконати в будь-якому разі».

**Оновлення:** закрий BT (правий клік на іконці → Вийти), заміни exe, запусти. Дані лежать окремо, в `%LOCALAPPDATA%\BisonTime`.
